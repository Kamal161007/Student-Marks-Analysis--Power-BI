# Student-Marks-Analysis--Power-BI
# This project is used to make a power bi dashboard for 100 students
# It contains the following finding(depicted by various charts)
1. Average score percent by ethnicity of students.
2. Average score percentage by gender of the stdents.
3. Average score percentage by parental education.
4. Average score percentage by test preparation.
5. Average score percentage by ethnicity and parental education.
6. Top 5 students by average marks.
The project also filter the students based on the basis of:
a. Ethnicity
b. Gender
C. Parental education
d. Test preparation status.
All these filters are applicable by the use of slicers.
